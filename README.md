# SMS Fraud Detection

## Project Description
This project detects spam and potentially fraudulent SMS messages using machine learning.

## Features
- SMS message classification
- Text preprocessing and transformation
- Machine learning-based prediction
- Classification of messages as spam or legitimate

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Machine Learning

## Project Files
- `app.py` — Main application
- `predict.py` — Prediction logic
- `preprocess.py` — Text preprocessing
- `transformer.py` — Text transformation
- `svm.py` — SVM model code
- `train.py` — Model training
- `requirements.txt` — Required Python libraries
- `models/` — Saved model files
- `data/` — Dataset and related data files

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

Run the application using the command appropriate for your framework. For example, if it uses Streamlit:

```bash
streamlit run app.py
```

## Disclaimer
This application provides machine-learning-based SMS classification. Its predictions may not always be accurate.
